Memulai Project di Github

Saat pertama menginisiasi .git, branch utama akan berada di main. Tapi gak seru dong kalo kita cuma main-main di branch main wkwkkw. Jadi setiap commit atau perubahan final pastikan push dan commit di branch main, oleh sebab itu pentingnya berada di branch yang benar saat melakukan commit. Sebelum memulai upload project di github, struktur dan konfigurasi harus rapi, sehingga memudahkan dalam memahami apa yang terjadi jika memulai pekerjaan tertentu dengan git. konfigurasi global username git config --global user.name "yourname" git config --global user.email name@mail.com melihat konfigurasi: git config --list Autentikasi Saat push dll github tidak bisa lagi menggunakan password, oleh sebab itu beberapa cara untuk autentikasi bisa dengan: - SSH Key - Personal Access Token
